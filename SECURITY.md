# Security

Slash Command types into your terminal and holds the Accessibility and Automation permissions, so problems here matter.

## Reporting

Please report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/yohangwak/slash-command/security/advisories/new). Do not open a public issue for it.

Include the version, the terminal and agent involved, and steps to reproduce. You should get a first reply within a week.

## In scope

- Keys or text sent to a terminal or session other than the one in front
- Keys sent while a permission or approval dialog is showing
- Screen content written to the log or sent anywhere
- A way for another local program to make Slash Command type something

## Supported versions

Only the latest release receives fixes.
